\begin{abstract}
We study compositional generation in Stable Diffusion 3.5 and ask whether
natural-language conjunction (``A and B'') matches logical composition.
We compare monolithic prompting (CLIP AND), SuperDiff logical composition,
and hybrid guidance under shared-noise trajectory analysis.
Across controlled experiments, CLIP AND and SuperDiff follow distinct latent
paths and often converge to different semantic outcomes.
We then test whether a semantic anchor can regularize logical composition by
blending monolithic and SuperDiff velocity fields with a guidance weight
$\alpha$.
Our results support a practical view: semantic co-presence and logical
intersection are related but non-equivalent objectives, and the best
trade-off is obtained by explicit guidance interpolation.
Our benchmark currently contains 67 reproducible trajectory runs with fixed
configuration logging and per-run summaries.
\keywords{compositional generation, diffusion models, latent trajectories, guidance, logical operators}
\end{abstract}

\section{Introduction}
Compositional prompting is central to controllable text-to-image generation.
However, conjunction in language does not always match conjunction in model
inference.
This mismatch causes hybridization artifacts, spatial collapse, and unstable
object co-presence.

Our goal is to characterize this gap and propose a practical control strategy.
The paper is built directly from our experiment artifacts, not synthetic
illustrations.

\textbf{Main contributions.}
\begin{itemize}
  \item We provide trajectory-level evidence that CLIP AND and SuperDiff AND are dynamically different.
  \item We show that many SD3.5 failure cases can be reorganized as composition failures, not only sampling noise.
  \item We introduce and evaluate a hybrid guidance rule that interpolates monolithic and logical dynamics.
  \item We report reproducible protocols with shared noise, fixed seeds, and structured ablations.
\end{itemize}

\textbf{Paper scope.}
\begin{itemize}
  \item Focus model: Stable Diffusion 3.5 Medium.
  \item Focus question: semantic conjunction versus logical composition in latent dynamics.
  \item Focus outputs: trajectories, endpoint geometry, decoded images, and CLIP-based semantic probes.
\end{itemize}

\section{Background}
\textbf{Semantic conjunction vs. logical conjunction.}
In diffusion sampling, monolithic text prompting and score/velocity composition
are distinct operators.
They need not produce the same latent trajectory or endpoint image.

\textbf{Compositional operators used in this paper.}
\begin{itemize}
  \item \textbf{CLIP AND (monolithic):} one prompt ``A and B'' under standard CFG.
  \item \textbf{SuperDiff AND:} dynamic reweighting of concept velocities to satisfy balanced composition constraints.
  \item \textbf{PoE baseline:} additive composition of conditional scores/velocities.
  \item \textbf{Guided hybrid:} $(1-\alpha) v_{\text{mono}} + \alpha v_{\text{superdiff}}$.
\end{itemize}

\textbf{Evaluation setup.}
\begin{itemize}
  \item Model family: Stable Diffusion 3.5 Medium.
  \item Shared-noise protocol: all conditions start from the same $x_T$.
  \item Outputs per run: trajectory manifold, pairwise distances, decoded images, and summary metrics.
\end{itemize}

\textbf{Why trajectory-level analysis.}
\begin{itemize}
  \item Endpoint-only comparison hides when methods first diverge.
  \item Shared-noise trajectories isolate composition effects from random initialization.
  \item Per-step diagnostics reveal whether guidance acts early, mid, or late in denoising.
\end{itemize}

\section{Methodology}
We use one unified protocol for all benchmarked conditions.
Figure~\ref{fig:method-subplots} shows the per-condition trajectory artifact
produced by this pipeline.

\textbf{Pipeline.}
\begin{itemize}
  \item Fix a prompt set and scheduler settings.
  \item Sample all methods from the same initial noise $x_T$.
  \item Track latent trajectories at every denoising step.
  \item Compare methods using divergence onset, endpoint distance, and decoded outputs.
\end{itemize}

\textbf{Reproducibility controls from our run interface.}
\begin{itemize}
  \item Core controls: \texttt{--steps}, \texttt{--guidance}, \texttt{--seed}, \texttt{--projection}.
  \item Composition controls: \texttt{--superdiff-variant}, \texttt{--guided}, \texttt{--alpha}.
  \item Prompt modes: pairwise (\texttt{--prompt-a/--prompt-b}), multi-prompt (\texttt{--prompts}), negation (\texttt{--neg-prompt}).
  \item Ablation controls: \texttt{--no-poe}, \texttt{--lift}, and multi-seed sweeps.
\end{itemize}

\textbf{Hybrid guidance rule.}
\begin{equation}
v_{\alpha}=(1-\alpha)\,v_{\text{mono}}+\alpha\,v_{\text{superdiff}},
\end{equation}
where $v_{\text{mono}}$ is monolithic CFG velocity and
$v_{\text{superdiff}}$ is logical composition velocity.

\textbf{Metrics used throughout.}
\begin{itemize}
  \item Divergence onset step: first denoising step where pairwise trajectory distance becomes non-trivial.
  \item Endpoint L2 distance: final latent-space discrepancy between conditions.
  \item CLIP probe prediction: nearest text prototype in CLIP space for each output image.
\end{itemize}

\section{Semantic and Logical Composition Diverge in Latent Space}
We test whether semantic and logical conjunction are equivalent in practice.
They are not.

\textbf{Protocol.}
\begin{itemize}
  \item Conditions: prompt A, prompt B, monolithic AND, SuperDiff AND (and optional PoE).
  \item Controls: identical seed, identical scheduler steps, identical guidance scale.
  \item Diagnostics: divergence onset, endpoint distances, path length, and CLIP probe.
\end{itemize}

\textbf{Findings.}
\begin{itemize}
  \item CLIP AND and SuperDiff AND split early in latent space for many prompt pairs.
  \item Endpoint geometry often places SuperDiff closer to a latent midpoint than to monolithic endpoints.
  \item Kappa dynamics are time-varying, indicating adaptive concept balancing rather than fixed blending.
  \item Practical implication: semantic co-presence should not be assumed from logical score composition alone.
\end{itemize}
Figure~\ref{fig:divergence-spatial} gives a representative spatial example.

\textbf{Concrete evidence from benchmark runs.}
\begin{itemize}
  \item Run \texttt{20260216\_114652} (cat-left/dog-right): divergence onset at step 3; endpoint L2(CLIP, SuperDiff) $=377.7$.
  \item Run \texttt{20260217\_011236} (two-blue-apples/red-table): divergence onset at step 2; endpoint L2(CLIP, SuperDiff) $=407.1$.
  \item These early onsets indicate that divergence starts near the beginning of denoising, not only at late refinement.
\end{itemize}

\section{What Semantic Prompt Does Logical Composition Follow?}
We investigate the effective semantics induced by logical composition.
We frame this as a decoding and failure-analysis problem.

\textbf{Failure taxonomy from SD3.5 runs.}
\begin{itemize}
  \item \textbf{Count failures:} wrong number of objects under conjunctive prompts.
  \item \textbf{Spatial failures:} left/right or relative position constraints collapse.
  \item \textbf{Attribute binding failures:} colors or parts swap between objects.
  \item \textbf{Negation failures:} ``without X'' prompts leak the negated concept.
\end{itemize}

\textbf{Interpretation.}
\begin{itemize}
  \item SuperDiff outputs often satisfy parts of both prompts but can diverge from natural-language ``A and B'' semantics.
  \item This suggests logical intersection in latent dynamics is not a direct proxy for linguistic conjunction.
  \item The effective semantic target is task-dependent and can drift with prompt geometry.
\end{itemize}
Figure~\ref{fig:decoded-apples} illustrates this semantic gap on a counting-and-attribute prompt.

\textbf{CLIP probe observations from our runs.}
\begin{itemize}
  \item In run \texttt{20260217\_011236}, CLIP predicts the monolithic class for guided outputs but predicts a single sub-prompt class for pure SuperDiff.
  \item In run \texttt{20260216\_114652}, pure SuperDiff is pulled toward one component prompt under the CLIP probe.
  \item This supports the hypothesis that logical balancing and linguistic conjunction occupy different semantic neighborhoods.
\end{itemize}

\section{Adding the Semantic Prompt as a Third Constraint}
We test whether monolithic semantics can regularize logical composition.
The mechanism is SuperDiff-guided interpolation with sweep over $\alpha$.

\textbf{Method.}
\begin{itemize}
  \item Compute monolithic CFG velocity $v_{\text{mono}}$.
  \item Compute SuperDiff composite velocity $v_{\text{superdiff}}$.
  \item Blend them using $v_{\alpha}=(1-\alpha)v_{\text{mono}}+\alpha v_{\text{superdiff}}$.
\end{itemize}

\textbf{Empirical behavior under $\alpha$ sweeps.}
\begin{itemize}
  \item Small $\alpha$: stronger semantic naturalness, weaker strict compositional balancing.
  \item Large $\alpha$: stronger logical balancing, higher risk of semantic drift.
  \item Mid-range $\alpha$: best trade-off in many spatial and object co-presence prompts.
\end{itemize}

\textbf{Quantitative examples from $\alpha$ runs.}
\begin{itemize}
  \item Run \texttt{20260217\_005615} (book-left/bird-right): L2(CLIP, SuperDiff) $=247.1$, while L2(CLIP, Guided $\alpha=0.3$) $=146.0$.
  \item Run \texttt{20260217\_011236} (two-blue-apples/red-table): L2(CLIP, SuperDiff) $=407.1$, while L2(CLIP, Guided $\alpha=0.3$) $=129.3$.
  \item Guided trajectories keep semantic anchoring while preserving part of logical correction.
\end{itemize}

\textbf{Geometry insight.}
\begin{itemize}
  \item Forcing CLIP-like behavior toward SuperDiff trajectories reveals a non-trivial manifold gap.
  \item The hybrid path can reduce this gap without collapsing to either extreme.
  \item This supports guided composition as a controllable bridge between semantics and logic.
\end{itemize}

the $\alpha$ sweep.

\section{Conclusion}
This paper separates two objectives in compositional generation:
semantic conjunction and logical composition.
They are related but not identical in SD3.5 trajectory dynamics.

\textbf{Takeaways.}
\begin{itemize}
  \item Logical composition alone is insufficient for reliable semantic co-presence.
  \item Shared-noise trajectory diagnostics expose where and when methods diverge.
  \item Guided interpolation with $\alpha$ offers a practical and tunable solution.
\end{itemize}

\textbf{Practical recommendation from our experiments.}
\begin{itemize}
  \item Start with monolithic prompting for semantic naturalness.
  \item Add guided logical correction with moderate $\alpha$ to improve compositional balance.
  \item Use trajectory divergence metrics as an early warning signal for failure cases.
\end{itemize}

\textbf{Limitations and next steps.}
\begin{itemize}
  \item Current results focus on SD3.5 Medium and selected prompt families.
  \item Larger-scale human evaluation and automated compositional scoring are needed.
  \item Future work should study model scaling, scheduler effects, and stronger semantic priors.
\end{itemize}
